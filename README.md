# DOYSCHOOL

React와 Vite를 사용해 제작한 반응형 영어학원 포트폴리오 웹사이트입니다.

## Demo

https://raccooney.github.io/english-academy-portfolio/

## 주요 기능

* 반응형 웹 디자인
* Sticky Header
* 메뉴 클릭 시 부드러운 스크롤 이동
* Hero 이미지 및 오버레이
* About 학원 소개
* Teachers 강사진 카드
* Curriculum 과정별 카드
* Reviews 후기 리스트 및 별점 표시
* 전화 및 이메일 문의 링크
* 상담 신청 버튼
* 모바일 화면 대응

## 사용 기술

* React
* Vite
* JavaScript
* HTML
* CSS
* Git / GitHub
* GitHub Pages
* GitHub Actions

## 프로젝트 목적

React와 CSS를 활용해 실제 영어학원 홈페이지 형태의 반응형 웹사이트를 제작한 포트폴리오 프로젝트입니다.

첫 번째 포트폴리오에서 익힌 컴포넌트 구조, Flex 레이아웃, 반응형 디자인, Git 및 배포 과정을 복습하면서 직접 구현하는 비중을 높여 제작했습니다.

Teachers와 Reviews 영역은 배열과 `map()`을 활용해 데이터가 추가될 경우 화면에 쉽게 반영될 수 있도록 구성했습니다.

> This website is a portfolio demo and is not an actual English academy website.
